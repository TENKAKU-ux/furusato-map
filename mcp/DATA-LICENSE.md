# 同梱データの出典と利用条件

`data/furusato.json` は、次の公表資料を加工して作ったデータです。コード（`dist/`）の MIT ライセンスとは別に、それぞれの出典の利用条件に従います。使うときは、出典と加工したことを書いてください。

- 総務省「ふるさと納税に関する現況調査結果」（2026年7月31日公表）を加工して作成（[公共データ利用規約 第1.0版](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)）
- 政府統計の総合窓口（e-Stat）「住民基本台帳に基づく人口、人口動態及び世帯数」（令和8年1月1日現在）を加工して作成（[政府標準利用規約 第2.0版](https://www.e-stat.go.jp/terms-of-use)）
- 総務省「令和8年度 市町村別普通交付税決定額」「令和8年度普通交付税大綱」を加工して作成（公共データ利用規約 第1.0版）

加工の内容は、円単位への換算・丸め、都道府県の控除額の集計、差額の計算、人口と普通交付税の状態の結合などです。列の対応と検証の記録は <https://github.com/TENKAKU-ux/furusato-map/blob/main/docs/data.md> にあります。

このデータは個人が作成した非公式のもので、総務省とは関係ありません。差額は地方交付税・所得税の控除を含まず、実際の損益を示すものではありません。
