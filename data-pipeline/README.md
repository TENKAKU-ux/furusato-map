# データ加工

リポジトリのルートで実行する。Python 3.10以上、標準ライブラリのみ。通信・元Excelの書換えは行わない。

生成・契約Schema検証：`python3 data-pipeline/build.py`

テスト：`python3 -m unittest discover -s data-pipeline -p 'test_*.py' -v`

`raw/SHA256SUMS` のExcel5本とPDF2本を照合してから原票を読み、契約v2の `public/data/furusato.json` と `data-pipeline/validation.json` を生成する。取得日は2026-10-18。人口・交付税Excel・交付税大綱は作成者が公式URLから直接取得し、既存の調査3本と報道資料の取得日は作成者の取得記録に基づく。報道資料は独立照合、大綱は普通交付税の状態の根拠に使う。入力のハッシュ不一致・コード重複/結合欠落・列定義変更・推移R7不一致・契約違反では失敗し、新しい出力を作らない。

`schema_check.py` は確定Schemaが使うDraft 2020-12のキーワードと `date` / `uri` 形式だけを検査する。未対応キーワードを検出したら失敗する。汎用のJSON Schemaエンジンではない。生成物は別途Draft 2020-12の汎用検証器でも照合する。

`validation.json` は結合の欠落/余剰、推移の対応不能、丸め前後の合計、円未満のR列17件、集計から除外した元表の控除集計行、代表値、出力サイズを残す。検査結果と全国報道資料照合の合否は `docs/data.md` を参照。加工・Pythonテストの成功だけで全国照合を合格とはしない。

`test_press.py` は保存済みの配信JSONと、`raw/press_001085011.pdf` の印字p.2・8・9・11から転記した固定値を照合する。全国値・47都道府県・代表値を検査し、PDF本文の抽出・通信・外部ツールは使わない。出典URL・ページ・PDFのSHA-256はテスト内、取得日と詳細な照合結果は `docs/data.md` に記録する。

`test_v2.py` は人口の1788結合・47県和、交付税の4字体差と4状態、大綱p.6の不交付86市町村、費用内訳、BC/BD集計、v1全団体・全フィールドの不変性を検査する。`validation.json` の `v2` に明細がある。費用原票の空欄20セルはnullを維持し、14件の合計・16組の内数比較は検算不能として残す。PythonテストとSchemaが成功しても、この費用の全件受入を合格とはしない。
